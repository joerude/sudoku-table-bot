# 🧩 Sudoku League Bot

Телеграм-бот, который ведёт учёт соревновательной игры в судоку
([usdoku.com](https://www.usdoku.com/)) между друзьями: очки, места, сезоны, дуэли,
рейтинг. Один групповой чат, один инстанс, SQLite.

## Как это работает

1. Каждый игрок в группе пишет `/setnick ТвойНикНаUsdoku`. Команда сразу
   регистрирует игрока, отдельный `/join` не нужен. Ник должен совпадать с именем
   в комнате usdoku, иначе бот не узнает тебя в игре.
2. Кто-то пишет `/play` и выбирает режим. Бот сам создаёт комнату на usdoku и
   присылает ссылку.
3. Когда доиграете, бот сам видит итог на usdoku и записывает очки и места.
   Если авто-учёт не сработал, результат вносится вручную через `/result`.

## Возможности

- **Игра** - `/play` открывает хаб: обычная игра (выбор сложности), дуэль 1 на 1,
  «позвать всех» (`/invite`, кнопка «Я в деле»). То же командами `/newgame`,
  `/duel`, `/invite`. Комнату, которую бот не смог создать, можно создать
  вручную и привязать: `/code КОД`.
- **Авто-учёт** - бот опрашивает usdoku и записывает результат. Порядок мест берётся
  из времени финиша, не доигравшие получают DNF (0 очков). Время решения
  сохраняется для статистики скорости.
- **Очки** - настраиваемая таблица на сезон (по умолчанию `3 / 1 / 0`).
- **Сезоны календарные** - сезон длится месяц. Он закрывается раньше, если лидер
  набрал порог (по умолчанию 100 очков), или в конце месяца, если лидер набрал хотя
  бы 10 очков. «Тихий» месяц (лидер меньше 10 очков) не закрывается, а
  продлевается до конца следующего. Прошлые сезоны смотрятся через `/season N`.
- **Статистика** - `/stats` с вкладками: таблица, моё, скорость, дуэли, история,
  рекорды, актив (кто зовёт играть, кто затих). Отдельные команды `/status`,
  `/me`, `/speed`, `/duels`, `/history` открывают те же вкладки.
- **Рейтинг** - `/rating`: вечная лестница ELO (не сбрасывается по сезонам) и
  корона 👑 текущему первому. Изменение рейтинга пишется в пост результата.
- **Дуэли** - `/duel` вызывает соперника. Дуэли не входят в очки сезона, у них свой
  счёт побед и поражений, но они учитываются в рейтинге.
- **Справочник техник** - `/learn`: 18 приёмов решения, от одиночек до цепочек,
  со ссылками на разбор.
- **Недельный дайджест** - итоги недели в понедельник, `/weekly` показывает их сразу.
- **Напоминания** - про незаписанные игры и (по желанию) ежедневное.
- **Удаление с подтверждением и возвратом** - soft delete, возврат в один тап.
- **Экспорт и бэкап** - `/export` отдаёт игры сезона в CSV, `/backup` полную копию базы.

## Быстрый старт (Docker)

1. Получи токен у [@BotFather](https://t.me/BotFather).
2. Скопируй конфиг и впиши токен:
   ```bash
   cp .env.example .env
   # отредактируй BOT_TOKEN в .env
   # по желанию: впиши свой Telegram id в OWNER_TG_ID
   ```
3. Запусти:
   ```bash
   docker compose up -d --build --force-recreate
   ```
4. Проверь, что бот поднялся: `docker compose logs bot | tail` должен показать
   `bot started`.
5. Добавь бота в групповой чат и напиши `/start`.

`OWNER_TG_ID` (необязательно) нужен для `/backup` и `/restore`: владелец может делать
это в любом чате, включая личку с ботом. Без него бэкап и восстановление доступны
только админам группы и только внутри группы.

Данные лежат в `./data/sudoku.db` (примонтированный volume), переживают перезапуск.

### Обновление

```bash
docker compose up -d --build --force-recreate
```

`--force-recreate` обязателен: без него `docker compose up -d --build` может оставить
запущенным старый контейнер со старым бинарём. Если после деплоя нового поведения
нет, образ взял несвежий кэш: `docker compose build --no-cache bot`, затем снова
`docker compose up -d --force-recreate`. (Рецепт `just up` не пересоздаёт
контейнер, для обновления используй `just rebuild` или команду выше.)

## Добавить бота в чат

1. Создай бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и вставь токен в `.env`.
2. **В группу:** открой группу → **Добавить участников** → найди бота по нику → добавь.
3. **Сделай бота админом с правом удалять сообщения.** Без этого бот работает, но
   служебный шум (ошибки, подсказки, ответы на неверные команды) не исчезает сам.
   С правом удаления такие сообщения и команда, которая их вызвала, пропадают
   через 20 секунд, а результаты, таблицы и игровые посты остаются. Других прав
   не нужно.
4. В группе: `/start`, затем каждый игрок делает `/setnick ТвойНикНаUsdoku`.

При добавлении в группу бот сам пишет приветствие с быстрыми кнопками, а **меню
команд** (кнопка «/») регистрирует при старте, ручной `/setcommands` в @BotFather
не нужен. Меню зависит от того, кто смотрит:

| Где | Команды в меню |
|-----|----------------|
| Группа, все участники | `play`, `stats`, `rating`, `setnick`, `learn`, `help` |
| Группа, админы | то же + `settings`, `removeplayer`, `backup` |
| Личка с ботом | `help`, `learn` |

> ⚠️ В группе команды набирай **`/start`** (или жми из меню «/»), а не
> «@бот команда»: «@бот /start» Telegram шлёт как обычный текст, и это не команда.
> Если опечататься в команде, бот эфемерно подскажет похожую.

Бот работает в группе. В личке он понимает только `/start`, `/help`, `/learn`, а для
владельца ещё `/backup` и `/restore`; остальные команды там вежливо отклоняются.

## Команды

| Команда | Описание |
|---------|----------|
| `/setnick <ник>` | Ник на usdoku; регистрирует игрока, если он ещё не в лиге. Ник уникален в чате |
| `/join [имя]` | Зарегистрироваться или сменить отображаемое имя |
| `/play` | Хаб: игра, дуэль, позвать всех |
| `/newgame`, `/duel`, `/invite` | То же, что кнопки `/play`, командами |
| `/code <КОД>` | Привязать вручную созданную комнату usdoku к текущей игре |
| `/result` | Записать результат вручную (тап по порядку финиша) |
| `/stats` | Вся статистика вкладками |
| `/status`, `/me`, `/speed`, `/duels`, `/history` | Отдельные вкладки `/stats` |
| `/season [N]` | Сводка текущего или архивного сезона |
| `/rating` | Лестница ELO и корона |
| `/learn` | Справочник техник |
| `/players` | Кто играет и их ники usdoku |
| `/weekly` | Итоги недели сейчас |
| `/export` | Игры сезона в CSV |
| `/settings` | Показать настройки; менять (порог, очки, мин. игроков, напоминания, дайджест) может админ группы |
| `/removeplayer <имя>` | Убрать игрока, прошлые игры сохраняются (админ) |
| `/backup` | Скачать базу (владелец бота или админ группы); восстановить: прислать файл с подписью `/restore` |

## Локальный запуск (без Docker)

```bash
export BOT_TOKEN=...   # токен от BotFather
export DB_PATH=./data/sudoku.db
export OWNER_TG_ID=...  # необязательно, твой Telegram id
go run ./cmd/bot
```

## Тесты

```bash
go test ./...
```

## Команды разработки (just)

[`just`](https://github.com/casey/just) - таск-раннер. Установка:
`brew install just`, `cargo install just` или `apt install just`.
Полный список: `just` (или `just --list`).

| Команда | Что делает |
|---------|------------|
| `just run` | Локальный запуск (из `.env`, БД в `./data`) |
| `just check` | `build` + `vet` + `test` (перед коммитом) |
| `just test` | Тесты |
| `just fmt` | Форматирование кода |
| `just up` | Собрать образ и поднять в Docker (не пересоздаёт контейнер) |
| `just rebuild` | Чистая пересборка (`--no-cache`) + пересоздание |
| `just logs` | Живые логи контейнера |
| `just restart` | Перезапустить без пересборки |
| `just down` | Остановить и удалить контейнер |
